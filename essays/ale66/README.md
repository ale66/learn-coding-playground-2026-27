# Extracting and Analysing Messages from Telegram Channels

An exam project that downloads messages from public Telegram channels with Python and [Telethon](https://docs.telethon.dev)

> **Course:** _Coding for Computational Social Science_  
> **Author:** _ale66_  
> **Date:** _12/2026_

---

## Aims

1. Collect messages from one or more **public** Telegram channels.
2. Turn them into a clean dataset (CSV or JSON).
3. Answer at least one research question with the data.
4. Document the method so that someone else can repeat it.

## Research question

_The October 2026 riots in Milan and elsewhere: how did posting activity evolve over time?"_
