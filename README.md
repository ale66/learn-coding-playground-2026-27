![](./imgs/spectator.png)

Get fresh data from [data.spectator.co.uk/migration](https://data.spectator.co.uk/migration){target="_blank"}

Compute some interesting value, e.g.,

**a.** Albanians as a pc of all migrants (bars? pies?)\

**c.** the Q. with most arrivals (Summer?)\
**d.** average Albanians/month\
**e.** Albanians vs. Others (x,y scatterplot)
